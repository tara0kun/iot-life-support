# 運用で守ること（家族向け）

> このシステムは祖母の生活を記録しています。
> **記録そのものより、本人にどう接するかのほうが大事です。**
>
> この内容は 2026-05-04 に作られた家族用マニュアルから救出しました
> （`claude/family-manual-docs-XjPnO` ブランチ。2026-10-24 に整理して削除）。

## 絶対に守ること

### 1. 「監視している」と言わない

- タブレットは **「記録帳」** として説明してあります
- カメラの存在も伏せてあります

### 2. 「また食べたでしょ」と直接指摘しない

- タブレットが「さっき食べましたよ」とやさしく伝えます
- 家族は **記録に乗っかる** かたちで接してください
  （「そうみたいだね、お花育ったね」のように）

### 3. 家族の操作は本人の前でやらない

- ロック解除・記録の編集・伝言の送信などは別室で
- 本人は **「機械の調子が悪い」** と思っています

### 4. 炊飯器のロック解除は慎重に

- 「食べたがっているから」だけで解除しない
- **本当に必要なときだけ**（家族が一緒に食事するなど）

### 5. 浴室の緊急通知は最優先

- 「浴室で30分、脱衣所の人感が反応なし」が来たら、
  **すぐ様子を見に行くか電話してください**
- 浴槽の中は見えていません。長風呂でも出ますが、
  本当に動けなくなっている場合と見分けがつきません

---

## 本人に伝わらないこと

家族の操作は、祖母側のタブレットには **一切表示されません**。

- 家族が記録を編集・削除した
- 家族が「かんたん記録」で記録を付けた
- 家族が炊飯器をロック／解除した
- 家族同士の LINE のやり取り

**「機械が勝手に記録している」と思ってもらうのが基本設計** です。

## 本人が押せる唯一のボタン

スタンプカードの未達成項目に「**できた**」ボタンが出ます。
押すと、システムが裏でセンサー記録と照合します。

| 照合の結果 | 本人の画面 | 家族の LINE |
|---|---|---|
| センサー記録あり | スタンプが付く | 「確認済み」 |
| センサー記録なし | スタンプは付かず「家族に伝えてください」 | 「確認してください」 |

このため、**家族が知らないところで適当にスタンプが付くことはありません**。
30分のクールダウンが入るので連打もできません。

> 2026-10-24 時点では、このボタンは長く押されていません。
> タブレット自体は動いていますが、本人は使っていない状態です。

## 1日のおすすめ運用

| 時間 | やること |
|---|---|
| 朝 | LINE に `状況` を送って様子確認 |
| 昼 | 通知が来たら対応。なければ気にしない |
| 夕方 | お風呂リマインドが来たら気にする |
| 夜22時 | 「1日のまとめ」が届く。ざっと目を通す |
| 日曜22時 | 「週次レポート」が届く。傾向を見る |

> **「気になったら LINE で `状況`」** これだけ覚えていれば足ります。
